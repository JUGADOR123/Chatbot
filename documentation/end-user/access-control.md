# Access Control

**Audience:** server owners managing players

The Access Control menu centralizes common player permissions and restrictions. Depending on the server configuration, use it to manage operators, bans, and the whitelist.

Use an operator grant only for trusted administrators. A whitelist is useful when the server should be private. A ban prevents a player from joining, while removing a ban allows the player to join again if no other restriction applies.

If a player cannot join, check the whitelist, bans, operators, and the server console before changing networking settings. Apply access changes carefully and restart only when the application or server distribution requires it.
