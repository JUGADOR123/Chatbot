# Managing a Server

**Audience:** people using the auto-mcs desktop interface

The Server Manager is the main place to launch, stop, inspect, and configure a managed server. The custom console shows startup output, runtime messages, and crash information.

The server settings include common server properties and controls for the selected world, version, distribution, network settings, player limit, MOTD, and gameplay options. auto-mcs can update supported server files and switch distributions when the selected configuration permits it.

Use the server directory action when you need to inspect files manually. Make a backup before editing server files, changing distributions, or installing a large collection of mods and plugins.

If a server does not start, first inspect the console and crash report, confirm that Java initialization completed, and retry without recently added add-ons.
