# Remote Management with Telepath

**Audience:** users who need to manage a server from another auto-mcs instance

Telepath is auto-mcs's remote management feature. It can connect a local auto-mcs client to an auto-mcs instance running on another computer, VPS, or cloud machine.

On the host, enable sharing and display the pairing information. On the client, choose the Telepath pairing flow, enter the host address and port, and complete the pairing step. Once paired, remote servers appear in the Server Manager and can be managed similarly to local servers.

Treat pairing codes, access tokens, host addresses, and user-management screens as private administrative information. Revoke or restrict an unfamiliar paired user instead of sharing credentials publicly.

Telepath is an advanced feature. For a normal local server, use the desktop Server Manager and playit integration first.
