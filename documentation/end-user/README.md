# End-user Knowledge Base

This directory contains the curated knowledge layer for people running the
prebuilt auto-mcs application. It is intentionally organized around tasks a
server owner performs rather than the auto-mcs source tree.

## Categories

- **Installation:** download, extract, launch, and first Java initialization
- **Server creation:** templates, distributions, modpacks, and imports
- **Server management:** launch, console, settings, worlds, and versions
- **Add-ons:** mods, plugins, add-ons, and modpacks
- **Networking:** friends joining, firewall, ports, and playit.gg
- **Backups:** saving, restoring, and recovery
- **Access control:** operators, bans, and whitelist management
- **Troubleshooting:** startup, import, connection, and add-on failures
- **Telepath:** remote management and pairing

The machine-readable [catalog.json](catalog.json) supplies category, audience,
keywords, and source metadata to the retrieval index. The original upstream
guide cache remains available for broader context, but these pages are ranked
as the preferred end-user evidence.

## Out of scope by default

The answerer should abstain from developer-focused requests about amscript API
internals, source builds, Python modules, Telepath endpoints, or contributing
to the auto-mcs repository. Those topics can be documented separately later
without polluting the public support path.
