# Mods, Plugins, and Modpacks

**Audience:** server owners, not script or add-on developers

The Add-on Manager can search for, install, update, enable, disable, and import supported mods and plugins. The available ecosystem depends on the server distribution. For example, Fabric and Forge use mods while Paper, Spigot, and CraftBukkit commonly use plugins.

Use the built-in browser when possible so the application can keep track of installed add-ons. When importing a JAR manually, confirm that it belongs to the selected Minecraft version and server distribution.

Changes to add-ons commonly require a server restart. If a server stops starting after an add-on change, disable the newest add-on first, inspect the crash report, and confirm version compatibility.

Modpacks can be installed through the built-in browser or imported from supported `.zip` and `.mrpack` files. Keep a backup before replacing an existing modpack or changing its distribution.
